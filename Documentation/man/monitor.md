# monitor

## Name

monitor - AetherMon performance counters

## Synopsis

```
monitor
```

## Description

Dumps IRQ, syscall, JIT, disk and network counters. Available only in builds made with `--features monitor`.

## Mechanism

AetherMon counters: IRQs, syscalls, memory, JIT, network, disk.
