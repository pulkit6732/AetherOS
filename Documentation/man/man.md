# man

## Name

man - full manual page for a command (same as help <command>)

## Synopsis

```
man <command>
```

## Description

Shows the manual page for one command: NAME, SYNOPSIS, DESCRIPTION,
MECHANISM (which part of the kernel does the work) and SEE ALSO.

## Mechanism

Same renderer as help <command>; pages are compiled in.
