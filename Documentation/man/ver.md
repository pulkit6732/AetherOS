# ver

## Name

ver - version, build and boot-check totals

## Synopsis

```
ver
```

## Description

Prints the version label, build revision, enabled features and the number of
verdicts printed during this boot. The count is measured, not a security proof.

## Mechanism

Build-time version string plus the UART verdict counter.
